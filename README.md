# Expense Tracker

A full-stack **Expense Tracker web application** built using **Flask**, designed to help users track expenses, analyze spending patterns, and stay within a monthly budget.

---

## Features

- Add, edit, and delete expenses (CRUD)
- Category-wise expense analytics
- Monthly spending limit with dynamic donut chart
- Color-changing limit indicator (green → orange → red)
- Filters by month and category
- Dark mode toggle 
- Clean and responsive Bootstrap UI
- Chart.js visualizations

---

##  Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite, SQLAlchemy
- **Frontend:** HTML, CSS, Bootstrap 5
- **Charts:** Chart.js
- **Version Control:** Git, GitHub
